# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be kind, assume good faith, argue about ideas not people, and take
"no" gracefully — from maintainers about scope and from anyone about their
own boundaries.

One project-specific addition: **never post real people's data** — yours or
anyone else's — in issues, PRs, discussions, or fixtures. Use synthetic names
(`example.com` addresses, obviously fictional people). Maintainers will remove
it without warning.

Report conduct concerns through the same private channel as
[SECURITY.md](SECURITY.md).
